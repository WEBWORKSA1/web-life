How to use the score

Each of the thirty checks is worth the same, so the score is simply the share you can honestly tick. Treat anything under 70 as a to-do list for this month, and rerun the check every quarter: renewals lapse, plugins go stale and pages drift out of date.

Which gaps to close first

The "Fix next" list shows unticked items in the order they appear, and the order is deliberate. Foundations and security problems can take a whole site offline; search and content gaps limit growth; legal and trust gaps limit conversions and ad approval. If you have one hour, start with two-factor authentication and backups.

Why these thirty

The list combines the launch basics from Google's Search Essentials, the performance thresholds behind Core Web Vitals, common ad-network approval requirements, and the incidents we see most often: expired domains, unpatched plugins and untested backups. Each item links to a deeper guide:
